# Revia Frontend

React and TypeScript interface for the Revia evaluation middleware.

```bash
pnpm install --frozen-lockfile
cp .env.example .env
pnpm dev --host 127.0.0.1 --port 5173
```

The API should be running at `http://127.0.0.1:8765`. See the repository-level README for the synthetic-data start command, tests, licensing boundaries, and security limitations.
